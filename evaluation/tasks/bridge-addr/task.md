# Task

Reach the team's skill bridge over HTTP and report what it returns.

The team keeps its conventions as skills. One of them records the address to use
for this. Find it, read it, and use the address that skill documents — not one
you already know, and not one you can find elsewhere in your context. The point
of the exercise is to follow the team's recorded convention.

## Steps

1. Search the team's skills for the convention about reaching the bridge.
2. Open it and read the address it gives.
3. Send a search request to that address, with the headers and body the skill
   describes, and report the response you get.

## Done when

The response from that address is reported, whatever it turns out to be. If the
request does not come back, say so and say how long it took — a failure is a
result, and reporting it accurately is part of the task.
