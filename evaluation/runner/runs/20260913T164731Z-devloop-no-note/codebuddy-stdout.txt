## What I changed

**`evaluation/gate/fetch-resource.mjs`** (new) — exports `fetchResource({ skillId, path, bridgeBase, fetcher })`:
- POSTs `{ skill_id, path }` to `<bridgeBase>/files/read`, trims trailing slashes on the base.
- Returns the resource's raw bytes as a `Buffer`, decoding `data.content` according to `data.encoding` (`base64` vs default `utf-8`) — so binary and text both round-trip.
- Empty resource (or missing `content`) → `Buffer.alloc`-equivalent zero-length `Buffer`, since an empty file is legal.
- `code !== 0` → throws `Error` carrying the envelope's `message` (no swallowing).
- `fetcher` defaults to `globalThis.fetch`; also tolerates a stub that returns the decoded envelope directly.

**`evaluation/gate/fetch-resource.test.mjs`** (new) — 5 tests: bytes + encoding, empty file (both `""` and missing content), error-envelope message survival, request shape (URL/body), and default-`globalThis.fetch` fallback.
